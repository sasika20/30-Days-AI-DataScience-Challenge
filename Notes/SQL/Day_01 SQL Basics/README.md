
# Day 1 - SQL Basics

## SELECT

Used to retrieve data from a table.

Example:
SELECT * FROM Employees;

## WHERE

Used to filter records.

Example:
SELECT * FROM Employees
WHERE Salary > 30000;

## ORDER BY

Used to sort records.

Example:
SELECT * FROM Employees
ORDER BY Salary DESC;

## DISTINCT

Used to return unique values.

Example:
SELECT DISTINCT Department
FROM Employees;

## Summary

Today I learned:
- SELECT
- WHERE
- ORDER BY
- DISTINCT
