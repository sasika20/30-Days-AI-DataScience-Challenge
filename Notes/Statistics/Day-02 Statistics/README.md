
# Day 2 - Statistics

## Range

Range measures the spread of data.

### Formula

Range = Maximum Value - Minimum Value

### Example

Dataset:

10, 20, 30, 40, 50

Range = 50 - 10 = 40

---

## Variance

Variance measures how far data points are from the mean.

### Formula

Variance = Σ(x - Mean)² / N

### Uses

- Data Analysis
- Machine Learning
- Risk Assessment

---

## Standard Deviation

Standard Deviation is the square root of variance.

### Formula

Standard Deviation = √Variance

### Importance

- Measures data consistency
- Helps identify variation

---

## Key Takeaways

- Range shows overall spread.
- Variance measures average squared deviation.
- Standard deviation measures average variation from the mean.
