
# Day 2 - Power Query Basics

## What is Power Query?

Power Query is a data transformation tool in Power BI.

## Functions

- Import Data
- Clean Data
- Transform Data
- Merge Tables

---

## Data Import

Supported Sources:

- Excel
- CSV
- SQL Server
- Web Data

---

## Data Cleaning

Common Tasks:

- Remove Duplicates
- Replace Values
- Handle Missing Data
- Change Data Types

---

## Advantages

- Automates cleaning process
- Saves time
- Improves data quality

---

## Key Takeaways

- Power Query prepares data before visualization.
- Essential for Power BI projects.
