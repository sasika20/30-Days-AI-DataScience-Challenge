
# Day 1 - Power BI Basics

## What is Power BI?

Power BI is a Business Intelligence tool developed by Microsoft used to visualize and analyze data.

## Components of Power BI

- Power BI Desktop
- Power BI Service
- Power BI Mobile

## Features

- Data Import
- Data Transformation
- Data Visualization
- Dashboard Creation
- Report Sharing

## Common Visualizations

- Bar Chart
- Pie Chart
- Table
- Card
- Line Chart

## Key Takeaways

- Power BI helps transform raw data into meaningful insights.
- It is one of the most demanded tools for Data Analysts.
