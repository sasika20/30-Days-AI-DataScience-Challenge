
# Day 1 - Excel Basics

## What is Excel?

Microsoft Excel is a spreadsheet application used for data entry, analysis, calculations, and reporting.

## Common Uses

- Data Entry
- Data Cleaning
- Data Analysis
- Reporting
- Dashboard Creation

## Basic Formulas

### SUM

Adds values.

Example:
=SUM(A1:A10)

### AVERAGE

Calculates the average.

Example:
=AVERAGE(A1:A10)

### COUNT

Counts cells containing numbers.

Example:
=COUNT(A1:A10)

### IF

Performs logical tests.

Example:
=IF(A1>50,"Pass","Fail")

## Key Takeaways

- Excel is widely used in Data Analytics.
- Formulas help automate calculations.
- Understanding Excel fundamentals is essential before Power BI.
