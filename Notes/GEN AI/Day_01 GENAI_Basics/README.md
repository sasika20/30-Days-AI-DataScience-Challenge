
# Day 1 - Generative AI Introduction

## What is Generative AI?

Generative AI is a type of Artificial Intelligence that creates new content such as text, images, audio, and code.

## Examples

- ChatGPT
- Gemini
- Claude
- Midjourney

## Applications

- Content Creation
- Code Generation
- Chatbots
- Image Generation

## Benefits

- Increased Productivity
- Automation
- Creativity Enhancement

## Key Takeaways

- Generative AI creates new content from learned patterns.
- It is transforming many industries.
