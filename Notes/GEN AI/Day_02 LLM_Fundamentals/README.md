
# Day 2 - LLM Fundamentals

## What is a Token?

A token is a small unit of text processed by an LLM.

Examples:

"Data Science"

May be split into multiple tokens.

---

## Context Window

Context Window is the amount of information an LLM can remember during a conversation.

Larger context windows improve understanding.

---

## Hallucination

Hallucination occurs when an AI generates incorrect or fabricated information.

Example:

Providing a fake reference or incorrect fact.

---

## Importance

- Understanding model limitations
- Designing better prompts

---

## Key Takeaways

- Tokens are the building blocks of LLMs.
- Context affects response quality.
- Hallucinations are a known limitation.
