
# Day 2 - Python Collections

## Lists

Lists are ordered and mutable collections.

### Example

numbers = [10, 20, 30]

### Operations

numbers.append(40)

numbers.remove(20)

---

## Tuples

Tuples are ordered and immutable.

### Example

data = (10, 20, 30)

---

## Dictionaries

Store data in key-value pairs.

### Example

student = {
"name": "Sasika",
"age": 22
}

### Access Value

print(student["name"])

---

## Sets

Store unique values.

### Example

skills = {"SQL", "Python", "SQL"}

Output:

{"SQL", "Python"}

---

## Applications

- Lists → Product Lists
- Tuples → Fixed Records
- Dictionaries → User Information
- Sets → Unique Values

---

## Key Takeaways

- Lists are mutable.
- Tuples are immutable.
- Dictionaries store key-value pairs.
- Sets remove duplicates automatically.
