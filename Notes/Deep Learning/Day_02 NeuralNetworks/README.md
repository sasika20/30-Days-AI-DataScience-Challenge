
# Day 2 - Neural Networks

## Perceptron

Perceptron is the simplest neural network model.

Inputs → Weights → Activation Function → Output

---

## ReLU

Rectified Linear Unit

Formula:

f(x) = max(0,x)

Advantages:

- Fast
- Efficient

---

## Sigmoid

Formula:

f(x) = 1 / (1 + e^-x)

Output Range:

0 to 1

Used in binary classification.

---

## Tanh

Output Range:

-1 to 1

Provides better centered outputs.

---

## Key Takeaways

- Activation functions introduce non-linearity.
- ReLU is widely used in deep learning.
