
# Day 2 - Advanced Prompting

## Role Prompting

Assign a role to the AI.

Example:

Act as a Data Scientist and explain Linear Regression.

---

## Context Prompting

Provide background information.

Example:

I am a beginner learning SQL. Explain GROUP BY.

---

## Output Formatting

Specify desired format.

Example:

Provide the answer in markdown format.

---

## Benefits

- Better responses
- Improved accuracy
- Consistent outputs

---

## Key Takeaways

- Clear prompts generate better responses.
- Context improves AI understanding.
- Output instructions increase usability.
