
# Day 1 - Prompt Engineering Basics

## What is Prompt Engineering?

Prompt Engineering is the practice of designing effective instructions to obtain better responses from AI models.

## Types of Prompting

### Zero-Shot Prompting

Providing instructions without examples.

Example:
Explain Machine Learning.

### Few-Shot Prompting

Providing examples before asking a question.

### Chain of Thought Prompting

Encourages step-by-step reasoning.

Example:
Explain the solution step by step.

## Importance

- Improves AI responses
- Increases accuracy
- Enhances productivity

## Key Takeaways

- Well-structured prompts produce better outputs.
- Prompt Engineering is an important skill in Generative AI.
