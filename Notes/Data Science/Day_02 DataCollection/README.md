
# Day 2 - Data Collection

## What is Data Collection?

Data Collection is the process of gathering information for analysis.

---

## Types of Data

### Structured Data

Organized in rows and columns.

Examples:

- SQL Databases
- Excel Sheets

---

### Unstructured Data

Does not follow a predefined format.

Examples:

- Images
- Videos
- Emails
- Social Media Posts

---

## Sources of Data

- Surveys
- Databases
- APIs
- Sensors
- Websites

---

## Importance

- Foundation of Data Science
- Impacts model performance

---

## Key Takeaways

- Data quality affects results.
- Structured and unstructured data require different handling methods.
