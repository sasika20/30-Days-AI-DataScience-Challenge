
# Day 2 - Machine Learning Workflow

## Features

Features are input variables used to make predictions.

Example:

House Area
Number of Rooms

---

## Target Variable

Target variable is the output to be predicted.

Example:

House Price

---

## Train-Test Split

Data is divided into:

- Training Data
- Testing Data

Typical Split:

80% Training
20% Testing

---

## Workflow

1. Collect Data
2. Clean Data
3. Select Features
4. Train Model
5. Test Model
6. Evaluate Results

---

## Key Takeaways

- Features are inputs.
- Target is the output.
- Train-test split evaluates performance.
