
# Day 1 - Machine Learning Introduction

## What is Machine Learning?

Machine Learning is a subset of Artificial Intelligence that enables systems to learn from data without explicit programming.

## Types of Machine Learning

### Supervised Learning

Uses labeled data.

Examples:
- Linear Regression
- Logistic Regression

### Unsupervised Learning

Uses unlabeled data.

Examples:
- Clustering
- Association Rules

### Reinforcement Learning

Learns through rewards and penalties.

## Applications

- Recommendation Systems
- Fraud Detection
- Image Recognition

## Key Takeaways

- Machine Learning helps computers learn patterns from data.
- It is a core skill in Data Science.
